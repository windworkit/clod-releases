# Clod

Clod is a free app for Windows 10 and 11 (64-bit) that runs AI models on your own PC. Your chats stay on your PC. It was mainly built to help make Roblox games, and it also works for ordinary chat.

## Download

Download the installer from this link:

https://github.com/windworkit/clod-releases/releases/latest/download/Clod-Setup.exe

No account is needed, and nothing is uploaded.

## Install

1. Open the downloaded file, Clod-Setup.exe.
2. If Windows shows a blue "Windows protected your PC" box, click "More info", then "Run anyway". This box appears because the app is not code-signed.
3. Choose one of the options in the table below.
4. Follow the prompts until setup finishes.
5. Open Clod. If you chose an option with AI, Clod downloads its built-in model the first time you open it. The download is about 3 GB, so it can take a while.

## Which option should I pick?

| Option | What it does | Pick it if |
|---|---|---|
| Install Clod only | Installs the app with no AI model. You can add one later from inside the app. | You want to choose a model yourself later |
| Install Clod with AI | Installs Clod, and Ollama if you do not already have it. Clod's built-in model, Clod-1 Mini, downloads the first time you open the app. | You want Clod ready to use |
| Update | Checks for a newer version and installs it. Your chats are kept. | Clod is already installed |
| Uninstall | Removes Clod and its files. Ollama and its models are removed only if you tick those boxes. | You no longer want Clod |

## Updating

Open Clod, go to Settings, and click "Check for updates". You can also run the setup program again and choose Update.

## Uninstalling

Run the setup program and choose Uninstall. By default this also removes your chats and settings and the Clod-1 Mini model; untick those boxes to keep them. Ollama and its models are left alone unless you tick their boxes.

## Good to know

- Clod-1 Mini is a small model built on an open base model. It is slower and less capable than large online AI services.
- Speed depends on your PC. 16 GB of RAM or more is recommended.
- Chats stay on your PC.
- This page holds installer files only. The source code is not public.
